# nnounce Scripting Tutorials

These tutorials should serve as introduction to nnounce scripting. Scripts are written using Typescript.

Following tutorials are available:  

1. [Tutorial 1](./tutorial1/README.md) shows how to play local file when control input pin is set high, but with cooldown.  
1. [Tutorial 2](./tutorial2/README.md) builds on Tutorial 1 and adds loading some device information and sending them to virtual "log server".  
1. [Tutorial 3](./VSCodeSetup/README.md) shows how to set up nnounce scripting from Visual Studio Code.

Other guides and documentation for nnounce devices can be found at [https://docs.simpleway.cloud/nnounce/docs](https://docs.simpleway.cloud/nnounce/docs).
