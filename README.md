# nnounce Scripting Tutorials

These tutorials should serve as introduction to nnounce scripting. Scripts are written using TypeScript.

The following tutorials are available:  

1. [Tutorial 1](./tutorial1/README.md) – Plays a local file when the control input pin is set high, with a cooldown period.  
1. [Tutorial 2](./tutorial2/README.md) – Builds on Tutorial 1 by retrieving a user-defined variable and sending its value to an echo server via an HTTP request.
1. [Tutorial 3](./VSCodeSetup/README.md) – Guides you through setting up nnounce scripting in Visual Studio Code.

Additional guides and documentation for nnounce devices can be found at [https://docs.simpleway.cloud/nnounce/docs](https://docs.simpleway.cloud/nnounce/docs).
